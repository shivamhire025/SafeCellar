# SafeCellar

Compliance management platform for craft breweries and wineries (Phase 1: chemical SDS and inventory).

## Repository layout

| Path | Published to GitHub |
|------|---------------------|
| `safecellar/` | Yes — Next.js application |
| `PRD.md`, `DESIGN.md` | **No** — local-only product/design specs (see `.gitignore`) |

## Quick start

```bash
cd safecellar
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Demo login: `demo@safecellar.app` (any password).

Details: [`safecellar/README.md`](./safecellar/README.md)
